# 风格规范（style tokens）

两套主题共用一个原则：**墨水只花在数据上**。没有外框，没有竖向网格线，没有渐变和阴影（情景图的色带是唯一例外，因为渐变本身在表达「越远越不确定」）。

## teal 主题（深青）

适合数据展示型内容。气质是冷静、干净、偏科技。

| 用途 | 色值 | 说明 |
|---|---|---|
| 墨色 ink | `#0D4753` | 标题、第一条序列、署名 |
| 序列 2 | `#AACFD8` | 浅蓝灰，也是柱子的默认填充 |
| 序列 3 | `#F38C5C` | 橙，与深青形成冷暖对比，留给「对手」或「另一方」 |
| 序列 4 | `#1D886A` | 绿 |
| 序列 5 | `#E9B614` | 金 |
| 序列 6 | `#E84A47` | 红，留给最需要警觉的那条 |
| 刻度文字 | `#606060` | |
| 轴标题 | `#555555` | 加粗 |
| 网格线 | `#EAEAEA` | 只画横线，线宽 1 |
| 事件竖线 | `#A3A3A3` | 线宽 1.3 |
| 事件标签边框 | `#D9D9D9` | 白底圆角，文字 `#A3A3A3` 加粗 |

序列顺序即重要性顺序：最想让人看的排第一（深青），陪衬排第二（浅蓝灰）。超过 6 条线就该合并类别或拆成两张图。

**堆叠柱的家族配色**：一个家族一个色相，越新越深、越旧越浅。

| 家族槽位 | 由深到浅 |
|---|---|
| warm（暖） | `#E9514E` `#BF7573` `#C28D8B` `#C9AEAB` |
| cool（冷） | `#0D4753` `#19889F` `#ABD0D9` `#DEF0F0` |
| green | `#1D6B55` `#288B6F` `#8CC5B2` `#D6ECE4` |
| gold | `#B98600` `#F4BA01` `#F8D873` `#FCEFC4` |
| 零散小类 accents | `#288B6F` `#F4BA01` `#000000` `#999999` |

两个主要家族一暖一冷，读者先分清「哪一族」，再在同族里按深浅读「哪一代」。零散小类用高饱和点缀色，放在柱子最上面。

**版式**（画布 10 × 7.2 英寸，200 dpi）

- 标题：23 pt 加粗，墨色，左对齐，位于画布上方。过长自动折成两行并降到 20 pt。
- 来源：9.5 pt，`#808080`，左下角。单位：11 pt 加粗，绘图区左上角。
- 绘图区：左 12.5%、下 30%、宽 80%。下方留出大块空白给斜排的横轴标签和图例。
- 横轴标签：11 pt，逆时针 45°，右端对齐刻度。
- 图例：绘图区下方居中，一行排不下自动换行，无边框。线图用短线，柱图用小方块。
- 线宽 2.4，圆角连接。不加数据点标记。
- 事件标签：9.5 pt 加粗，白底圆角小牌，默认贴顶；同一事件多行文字拆成上下相邻的多块小牌；相邻事件自动错层。
- 事件本身就是主题时（如「某次发布后价格怎么走」），改用 `chip="ink"`：竖线和文字都用墨色，标签贴底。

## mono 主题（灰阶加单色高亮）

适合论证型内容。气质是克制、严谨，让读者的注意力只落在你上色的那一处。

| 用途 | 色值 | 说明 |
|---|---|---|
| 文字 | `#000000` | 标题、数据标签 |
| 柱子灰 | `#CCCCCC` | 默认柱色；预测期用 `#DEDEDE` |
| 层次灰 | `#B0B0B0` `#808080` `#595959` | 堆叠时由浅到深 |
| 线灰 | `#7F7F7F` | 线宽 2.6，菱形标记 |
| 高亮 highlight | `#CDD8F3` | 淡紫蓝，面积图和柱图里的「主角」 |
| 天蓝 sky | `#A1CCE4` | 构成图里要强调的那一块 |
| 藏青 navy | `#1F3C88` | 主角的名字、主角的线 |
| 肉橙 salmon | `#DA7756` | 对照方的线和名字 |
| 警示红 alert | `#C00000` | 增速、图内批注、箭头 |
| 情景绿 / 红 | `#7A9A3A` / `#E0281E` | 乐观 / 悲观的表格行 |
| 网格线 | `#E3E3E3` | 只画横线，线宽 0.8 |
| 分隔细线 rule | `#BFBFBF` | 标题下方、来源上方各一条 |

用色规则：一张图里灰色之外最多两种颜色。主角用 highlight 或 navy，对照方用 salmon，需要读者停下来看的数字用 alert。

**版式**（单图 7.2 × 4.9 英寸）

- 标题：12.5 pt 加粗黑色，左对齐，格式「图 N：结论句」或「Figure N: …」，可折两行。
- 标题下方一条细线，来源行上方一条细线，两条线之间是图。
- 单位写在左上角，10 pt 加粗，如「单位：百万元」。
- 只保留底部坐标轴线（黑色，1.2 pt），其余三边不画。
- 数据标签：柱顶标数值（10 pt 常规），线上标比率（10 pt 加粗）。两者相撞时柱值收进柱内或移到侧边。
- 图例：默认在绘图区上方居中；底部空间足够时可放下方。
- 来源：8.5 pt，左对齐，「资料来源：…」或「Source: …」。

## 强调记号（两套主题共用）

| 记号 | 样式 |
|---|---|
| 虚线框 `box` | 警示红（mono `#C00000`，teal `#E84A47`），线宽 1.3，虚线 4 点画 3 点空；红字 9.5 pt 加粗，白色描边，贴框内左上角 |
| 阶段框 | 灰 `#9A9A9A`，线宽 1.15，同一虚线；阶段名黑色 9.4 pt 加粗，定性警示红加粗，要点 8.7 pt，行距 1.32 |
| 红叉 `cross` | 警示红，线宽 3.4，透明度 0.72，圆头；中心一块白底红框小牌 |
| 贴线小牌 `pin` | 曲线上 4.2 pt 实心点；小牌底色 mono `#F2F5FB`、边 `#C9D3EA`（teal `#EEF4F5` / `#B9D3D9`），8.8 pt，引线同边色 |
| 编号圆点 `num` | 白底圆圈，黑色细边 0.9，数字 8.5 pt 加粗 |
| 时代条 `eras` | 绘图区上方一条墨色细线，时代名放在白底方框里（9 pt），时代分界处加粗短竖线，开放的最后一段末端画箭头 |
| 旁注栏 `notes` | 绘图区右侧，宽度约占画面三分之一；灰色虚线边框 `#BFBFBF`，标题藏青加粗，正文 9.2 pt，行距 1.35，每条前一个编号圆点 |
| 流程框 | 白底圆角，灰边 `#8C8C8C`；被圈出的环节边框改警示红，外加一个红色虚线椭圆 |
| 飞轮 | 中心实心圆藏青、白字；节点 9.2 pt 黑字，无框；箭头 `#595959` 线宽 1.1，沿圆弧顺时针；下方一句藏青 9.4 pt |
| 分层框 | 圆角框底色 `#F3F5FA`、边 `#C9D3EA`；业务名藏青 11 pt 加粗，收入方式警示红 9 pt，体量灰 8 pt；层与层之间一条 `#E3E3E3` 细线 |
| 环形图 | 环宽为半径的 30%，白色分隔线；主角藏青、第二主角天蓝，其余 `#D9D9D9` 起由浅到深的灰；标签在环外，带灰色引线 |
| 拆分加总 | 主角用藏青由深到浅、对照用肉橙由深到浅，从下到上越来越浅；总量线同主色，线宽 1.6，圆点标记 |

一张图里最多两种强调记号。阶段框和虚线框不要同时出现在同一段时间上。

## 字体

按顺序取第一个已安装的：

- 西文：Roboto、Inter、Helvetica Neue、Arial。
- 中文：Noto Sans CJK SC、Noto Sans SC、思源黑体、微软雅黑、苹方、文泉驿微米黑。

没有中文字体时库会给出警告，中文会显示成方框，必须先装字体再出图。不要用宋体、楷体等衬线字体，和本风格不搭。

## 用别的工具复刻

换成 ECharts、Plotly、Excel 也可以做出同样的观感，抓住这几条就够了：

1. 白底、无外框、只留横向浅灰网格线。
2. 标题左对齐、加粗，比正文大一到两级。
3. 色值照上表取，不要用工具默认配色。
4. 图例放在图外（下方或上方），不要压在数据上。
5. 事件用「竖线加小牌」，不要用箭头加大段文字。
